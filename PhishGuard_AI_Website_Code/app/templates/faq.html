FREQUENTLY ASKED QUESTIONS

PhishGuard AI FAQ

Short answers to common project and security questions.

What is phishing?

Phishing is a deceptive technique used to trick people into revealing information or performing an unsafe action.

Does HTTPS make a site safe?

No. HTTPS protects communication but does not prove that the site owner is trustworthy.

Can PhishGuard guarantee a URL is safe?

No. It provides an additional assessment and should not be treated as an absolute guarantee.

What does confidence mean?

It represents the model output for the current input and is not the same as overall model accuracy.

Why is domain age useful?

It can provide context, but it cannot classify a website by itself.

Why use machine learning?

Machine learning can learn patterns from labelled examples and apply them to new inputs.

Why Random Forest?

It is a practical ensemble classifier and a useful baseline for the prototype.

What is TF-IDF?

TF-IDF converts text into numerical weights based on term frequency and inverse document frequency.

Can every zero-day attack be detected?

No. New attack patterns may differ from training data.

What should I do after submitting credentials to a phishing site?

Change the affected password through the official service and enable MFA.
