ABOUT THE PROJECT

PhishGuard AI

AI-Based Phishing Detection and Secure Website Analysis System.

PROJECT PURPOSE

A cybersecurity learning prototype

PhishGuard combines a Flask web application, URL feature inspection, an offline-evaluated text-classification candidate, and SQLite scan history to demonstrate an end-to-end analysis workflow.

The project emphasizes explainability and honest evaluation. No ML model is enabled by default; evaluated candidates still require independent, later-dated validation before they can be promoted.
