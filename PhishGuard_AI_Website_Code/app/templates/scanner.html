CHECKS INCLUDED

What gets inspected?

  • ✓ HTTPS / HTTP scheme
  • ✓ Hostname and IP address
  • ✓ @ symbol and subdomain depth
  • ✓ Suspicious wording patterns
  • ✓ Long URLs and encoded characters
  • ✓ Punycode, port and known shorteners
  • ✓ Optional WHOIS domain-age lookup
These are heuristic signals, not proof of malicious intent.

Prototype limitation

The demo classifier is experimental because its training data contains duplicates and label leakage. The report separates heuristic indicators from the model prediction so neither is misrepresented as a definitive verdict.
