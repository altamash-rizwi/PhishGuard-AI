Understand every signal.

PhishGuard separates an explainable URL indicator score from the optional, uncalibrated machine-learning output.

01

Indicator score

A sum of documented URL-level rules. It is not a probability and is not calibrated against a representative real-world dataset.

02

Triggered findings

Each triggered rule explains what was detected and how many points it adds. Benign websites can trigger some rules.

03

ML model signal

The previous toy model is disabled. A model prediction appears only after an operator explicitly promotes a reviewed candidate.

!
Interpretation rule

A low indicator score or “potentially legitimate” model output does not prove that a website is safe. Verify sensitive domains independently.
