RESULT INTERPRETATION

Understanding a Scan Result

A result combines model output with URL and domain indicators.

Result components

Know what each part means.

0001

Legitimate / lower risk

The model considers the URL more consistent with legitimate examples.

Still verify important destinations.

0002

Potential phishing

The model identifies patterns more consistent with phishing.

Do not enter sensitive information until verified.

0003

Unavailable domain data

WHOIS data may not be available.

Continue with URL indicators.

0004

Model confidence

Probability describes the current prediction.

It is not overall model accuracy.

0005

Threat indicator

The interface summarizes the assessment.

Treat it as an additional signal.

0006

Recommendation

The system provides user guidance.

Follow official channels.

Indicator interpretation

Use multiple indicators together.

0001

URL Length

Very long URLs can sometimes hide suspicious paths or parameters.

Length alone is not proof of phishing.

0002

HTTPS

HTTPS encrypts communication between browser and server.

HTTPS does not prove that a site is trustworthy.

0003

IP Address

A raw IP address can be unusual for a public login page.

Treat unexpected IP-based links cautiously.

0004

@ Symbol

An @ symbol can contribute to misleading URL structures.

Inspect the actual hostname.

0005

Hyphen Count

Hyphenated domains can sometimes imitate recognizable names.

Consider this with other indicators.

0006

Dot Count

Multiple dots can make a URL difficult to interpret.

Identify the registered domain.

0007

Subdomains

Deceptive subdomains can contain brand-like words.

Read the hostname carefully.

0008

Suspicious Words

Words such as login, verify, reward or update may appear in deceptive links.

Words are contextual signals.

0009

Query Length

Long query strings can contain many parameters.

Inspect unexpected parameters.

0010

Path Length

Long paths can hide the meaningful destination.

Review the complete URL.

0011

Domain Age

A newly registered domain can be an additional caution signal.

Domain age is not a verdict.

0012

Redirects

Unexpected redirects can hide the final destination.

Verify the final destination.

0013

Punycode

Internationalized domains can create visually confusing names.

Inspect normalized hostnames.

0014

Port Number

Non-standard ports can be legitimate but deserve context.

A port alone is not proof.

0015

Fragment

Fragments can contain page state or navigation.

Treat them as one part of analysis.

Evaluation terms

Metrics planned for larger-data evaluation.

0001

Accuracy

Percentage of evaluated predictions that are correct.

0002

Precision

Among predicted phishing cases, the proportion actually phishing.

0003

Recall

Among actual phishing cases, the proportion correctly detected.

0004

F1-score

Harmonic mean of precision and recall.

0005

False Positive

Legitimate URL incorrectly flagged.

0006

False Negative

Phishing URL incorrectly classified as legitimate.

0007

Confusion Matrix

Table comparing actual and predicted classes.

0008

Test Set

Data kept separate from training for evaluation.
