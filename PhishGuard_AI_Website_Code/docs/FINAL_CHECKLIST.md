## Viva
Never claim:
- 100% detection.
- 100% accuracy.
- HTTPS means a website is safe.
- Domain age alone proves phishing.
- The confidence percentage is the same as model accuracy.

State clearly:
This is an academic prototype and the prediction is an additional security signal.
