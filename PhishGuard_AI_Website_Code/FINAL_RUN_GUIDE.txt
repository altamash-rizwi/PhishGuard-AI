PHISHGUARD AI - FINAL RUN GUIDE
================================

1. Open this project folder in VS Code.
2. Open PowerShell in the project root.
3. Install dependencies:
   python -m pip install -r requirements.txt

   Optional regression tests:
   python -m pytest -q

4. Download the official large dataset:
   python scripts/download_datasets.py

5. Train/evaluate:
   python scripts/train_and_evaluate.py --max-rows 100000 --trees 200

   For all available rows:
   python scripts/train_and_evaluate.py --max-rows 0 --trees 200

6. Start the application:
   python app/app.py

7. Open:
   http://127.0.0.1:5000

The command above starts the local development server only. For production,
review render.yaml and the deployment and operations instructions in README.md
and docs/OPERATIONS.md. Do not expose the Flask development server publicly.

  for your actual trained-model results.

  any URL is safe or malicious.
